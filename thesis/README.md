# Thesis source

This directory contains the v0.1.0 thesis draft: a reproducible, multi-agent experimental infrastructure for hybrid CEX/DEX ecosystems. It was consolidated from the proposal and draft materials in `../PRIMERA_ENTREGA`.

## Build

```bash
make pdf
```

The draft intentionally separates the research protocol from empirical claims. It contains no fabricated results; later versions should add figures, tables, and conclusions only after their linked experiments are reproducible.
