\chapter{Future Work}
\label{cap:futuro}

The following lines derive from the limitations in chapter~\ref{cap:discusion}.

\begin{enumerate}
  \item \textbf{Fee levels, latency and external volatility.} The simulator should incorporate the swap with fee of equation~\eqref{eq:comision}, a delay in the execution of arbitrage and a reference with volatility, in order to turn into results the factors that today are design candidates (table~\ref{tab:factores}). With a fee, the no-arbitrage band ceases to be a free parameter and is determined by $\gamma=-\log(1-f)$.
  \item \textbf{CEX with depth and latency.} Replacing the exogenous reference with an order book that responds to the AMM's trades would make it possible to study bidirectional feedback.
  \item \textbf{Concentrated liquidity.} Extending the AMM to positions over price intervals, which change the relation between reserve and impact.
  \item \textbf{Provider rules and order scaling.} Test gradual or estimated provider responses and order sizes tied to pool reserves against real event data; the current sensitivity fixes stylized rules and does not identify real LP behavior.
  \item \textbf{Precision planning.} Use a pilot that matches the signed shock design and stratify results by direction; the original pilot underpredicted H1 variance.
  \item \textbf{Reduced map.} Testing maps with more variables or with nonlinear terms, and evaluating whether they improve on the scalar autoregression; exploring other criteria for classifying regimes.
  \item \textbf{Full-system stability.} Define a Markov-complete state that includes agent memory and event state, then specify either a deterministic operating-point analysis or a stochastic stability notion before seeking a Lyapunov certificate for the nonlinear, piecewise simulator. The current certificate is limited to the autonomous fitted maps.
  \item \textbf{Engineering validation on a real pair.} Extend the current six-minute, three-swap DEX data-readiness pilot into a preregistered study only after selecting a pair and period, reviewing data rights, and establishing reproducible access to both venues. Align CEX bid/ask and depth with DEX reserve, swap and liquidity events; record fees, gas, execution delay, token orientation, block order and data rights; then test recovery persistence, relative order size and held-out surrogate performance. Do not transfer synthetic thresholds directly to production.
  \item \textbf{Engineering and pedagogy evaluation.} Measure whether the dashboard improves an operator's or student's ability to identify transient recovery and order-to-reserve stress; keep this evaluation separate from market validation.
\end{enumerate}
