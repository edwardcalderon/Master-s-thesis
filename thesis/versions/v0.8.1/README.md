# Manuscript v0.8.1

Bilingual source snapshot. It preserves the frozen synthetic confirmatory and
held-out model-comparison findings, adds John R. Ballesteros Parra as co-director,
and reports a separate descriptive summary of three public DEX swaps. The pilot is
not used to test H1--H3 or validate market behavior.

The DEX sample, attribution note, analysis script and generated summary are included.
From this directory, regenerate the public-only summary with `python3 experiments/empirical_data/analyze_dex_pilot.py --output figures/data/empirical_dex_pilot_summary.csv`. Build both PDFs with `make pdf` if pdfLaTeX and BibTeX are installed.
