# Manuscrito v0.8.1

Instantánea de fuentes bilingües. Conserva los hallazgos sintéticos confirmatorios y
la comparación reservada de modelos, añade a John R. Ballesteros Parra como codirector
y presenta un resumen descriptivo independiente de tres intercambios DEX públicos.
El piloto no se usa para contrastar H1--H3 ni para validar el comportamiento del mercado.

Se incluyen la muestra DEX, la nota de atribución, el script de análisis y el resumen
generado. Desde este directorio, regenera el resumen público con `python3
experiments/empirical_data/analyze_dex_pilot.py --output
figures/data/empirical_dex_pilot_summary.csv`. Compila ambos PDF con `make pdf` si están
instalados pdfLaTeX y BibTeX.
