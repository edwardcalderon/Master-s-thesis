# Manuscrito v0.8.3

Instantánea inmutable de las fuentes bilingües. Acota la pregunta principal a la grilla ensayada de capacidad/profundidad y a las trayectorias continuas del error; añade una comparación H1 con plazos equiparados, informa un resultado H2 posterior del error pico, estratifica la persistencia de E3 y limita la razón nominal flujo/capacidad a un diagnóstico exploratorio. Los resúmenes derivados reanalizan corridas archivadas; no añaden simulaciones ni validación externa.
