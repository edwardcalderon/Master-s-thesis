# Fuente de la tesis

Este directorio contiene el borrador de tesis v0.1.0: una infraestructura experimental reproducible y multiagente para ecosistemas CEX/DEX híbridos. Se consolidó a partir de la propuesta y los materiales de borrador de `../PRIMERA_ENTREGA`.

## Compilar

```bash
make pdf
```

El borrador separa intencionalmente el protocolo de investigación de las afirmaciones empíricas. No contiene resultados inventados; las versiones posteriores solo deben añadir figuras, tablas y conclusiones después de que los experimentos asociados puedan reproducirse.
