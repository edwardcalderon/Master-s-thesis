# Manuscript v0.5.1

Bilingual source snapshot for the pagination and annex corrections described in
[SNAPSHOT.md](SNAPSHOT.md). The findings and research question are unchanged.

Run `make pdf` from this directory with pdfLaTeX, BibTeX and the manuscript's LaTeX
packages installed (including `placeins`). This produces `main.pdf` (English) and
`es/main.pdf` (Spanish). Sources, bibliography and figure/table data are self-contained.
The repository's live build additionally checks bilingual metadata and rendered
research-question pagination before publication.
