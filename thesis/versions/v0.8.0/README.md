# Manuscript v0.8.0

Self-contained bilingual source snapshot. It preserves the v0.7.0 formal-mechanics and
Lyapunov discussion and adds the preregistered band-aware hybrid-map comparison,
held-out findings, engineering interpretation, and interactive evidence source data.

Build both editions with `make pdf` where pdfLaTeX, BibTeX, and required LaTeX packages
are installed. Figure data and export manifests are under `figures/data/` and
`figures/engineering/`.
