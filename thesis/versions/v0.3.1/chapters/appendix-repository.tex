\section{Reproducibility log for the MVP runs}

The current evidence is generated by the versioned runners in
\texttt{experiments/cex\_dex\_mvp/}. The deterministic mechanism run reported in
Section 3 is \texttt{cex-dex-mvp-f183520b90aa}; its model version is 0.3.0. The
associated deterministic sensitivity grid is \texttt{cex-dex-sweep-5e33d51c51a3}.
The stochastic selection run is \texttt{cex-dex-abm-a99f9be866b2} (model 0.4.0),
and its held-out map analysis is \texttt{cex-dex-h1c-43e446f04adf} (analysis 0.1.0).

From the repository root, the commands are:

\begin{quote}
\texttt{pnpm experiment:mvp:run} (deterministic reference run)\\
\texttt{pnpm experiment:mvp:check} (mechanics and accounting invariants)\\
\texttt{pnpm experiment:mvp:sweep} (deterministic selection grid)\\
\texttt{pnpm experiment:mvp:abm} (paired stochastic selection)\\
\texttt{pnpm experiment:mvp:h1c}\\
Pass \texttt{-{}-selection-run-dir} with the stochastic run directory identified above.
\end{quote}

Each run writes its configuration, summary and time series to its generated output
directory. The run metadata records the model or
analysis version, configuration and source checksums, runtime, seed set, and checksums
of generated artifacts. Output files are local generated artifacts and are not included
in this source snapshot; rerunning the commands recreates them. The exact configuration
and analysis protocols are versioned beside the runners. The stochastic selection
intervals use paired seeds and a normal approximation; they quantify seed variation
under the specified model and do not include uncertainty about agent design or
parameter selection.

The October 29 preliminary table is preserved in source snapshot
\texttt{thesis/versions/v0.2.0/}. Its referenced prototype and raw outputs are absent,
so those historical values are not claimed as reproduced by the runs above. All MVP
results are synthetic mechanism and model-selection outputs, not empirical market
evidence.
