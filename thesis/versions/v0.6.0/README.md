# Manuscript v0.6.0

Self-contained bilingual source snapshot. See `SNAPSHOT.md` for its findings and scope.

Run `make pdf` with pdfLaTeX, BibTeX and the required LaTeX packages. This generates
`main.pdf` in English and `es/main.pdf` in Spanish. Data tables and checksummed
manifests are under `figures/data/` and `figures/engineering/`.
