# Method and assumptions

The method note is the place to separate what is observed from what is assumed. Each published result should identify:

1. the source and version of its data;
2. the transformation or model applied;
3. the assumptions that could change the result;
4. the notebook or script that can reproduce the figure; and
5. the limitations that remain after the analysis.

The first public release keeps this page as a living template. Replace the checklist with the approved methodology once the research design is finalized.
