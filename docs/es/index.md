# Resumen de investigación

Este es el punto de entrada público a la tesis de maestría. El proyecto se organiza como un espacio de investigación y no como un producto de software: la pregunta va primero, la evidencia se puede inspeccionar y el PDF final sigue conectado con su fuente.

## ¿Qué contiene?

- `apps/web/` es la página pública y el visor de artefactos.
- `notebooks/` contiene cuadernos Jupyter pequeños y enlazables.
- `thesis/` contiene la fuente LaTeX del argumento escrito.
- `data/` define dónde deben ubicarse los conjuntos de datos brutos y procesados sin subir datos privados ni archivos pesados.

A medida que se estabilice la tesis, añade aquí la pregunta de investigación, la población, las variables y la contribución final. Hasta entonces, la estructura mantiene fiel la arquitectura pública sin inventar hallazgos.

El inglés es el idioma principal del proyecto. La aplicación pública está disponible en
inglés y español, y cada publicación final de la tesis incluye una traducción completa
al español. La documentación interna y los cuadernos pueden estar solo en inglés;
consulta la [política de idiomas](language-policy.md), las [instrucciones para compilar
ambos PDF](reproducibility.md) y el [MVP determinista CEX/DEX](../../experiments/cex_dex_mvp/README.md).
