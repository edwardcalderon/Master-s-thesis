# Método y supuestos

La nota metodológica debe separar lo observado de lo supuesto. Cada resultado publicado debe identificar:

1. la fuente y versión de sus datos;
2. la transformación o el modelo aplicados;
3. los supuestos que podrían cambiar el resultado;
4. el cuaderno o script que permite reproducir la figura; y
5. las limitaciones que persisten después del análisis.

La primera versión pública mantiene esta página como una plantilla en evolución. Sustituye la lista de comprobación por la metodología aprobada cuando se finalice el diseño de investigación.
